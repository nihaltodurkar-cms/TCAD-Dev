MPI Schwarz domain decomposition

Outer loop (not shown as separate nodes): each rank re-solves its own slab, then all 4 ranks exchange one interior plane of ψ/n/p with their neighbor(s) and check allreduce(MAX) convergence on ψ alone — capped at 20 iterations, tolerance 1e-4 (§9.6). This is NOT a distributed linear solve; each rank's own solve is an ordinary, unmodified single-process Device3D call.
